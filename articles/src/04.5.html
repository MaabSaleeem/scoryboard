Tournament Pro is bought for one tournament. You choose which one, then pay. Annual works differently: it covers every tournament you run for a year.

Before you start

  • You need a tournament already made. Pro is applied to an existing Basic tournament, not bought in advance.
  • This costs real money. Payment is taken in a secure checkout, and the card details are entered there, not in Scoryboard.
  • Check the currency first, beside the tabs. Prices are set per currency.

Upgrade one tournament to Pro

  1. Select Subscriptions in the sidebar, then the Tournament Pro tab.
  2. On the PRO card, select Start with PRO. {{shot:01|The PRO card on the Tournament Pro tab, priced £19.99, with the Start with PRO button outlined at the bottom.}}
  3. Scoryboard asks which tournament to upgrade. Only tournaments on the Basic plan are listed. {{shot:02|The Choose a Tournament for PRO window: a search box, a New Tournament button, and one row reading KB 04 Cup with a BASIC TOURNAMENT tag.}}
  4. Select the tournament. A tick appears on its row.
  5. Select Continue with PRO. Scoryboard hands you to its secure checkout to pay. {{shot:03|The same window with the tournament selected and ticked, and the Continue with PRO button outlined.}}

Subscribe to Annual instead

  1. On the ANNUAL card, select Start with ANNUAL. The checkout opens straight away - there is no tournament to pick, because Annual covers all of them. {{shot:04|The ANNUAL card, priced £215 with a 10% discount note, with the Start with ANNUAL button outlined.}}

What you will see

Selecting Continue with PRO or Start with ANNUAL opens the secure checkout. Scoryboard does not handle your card details itself and does not store them. The checkout shows the amount, takes the payment and returns you to Scoryboard.

Once the payment goes through, the tournament's plan changes from Basic to Pro and the limits lift: unlimited teams, sponsors, the advanced slideshow, Tournament Chat, and exporting fixtures.

Two things worth knowing before you pay.

  • Pro is per tournament. Buying it for one does not cover the next one. If you run several, compare the cost against Annual.
  • Annual is billed to your account, not to a tournament. It applies to every tournament while it is active.

If it does not work

  • The list is empty. You have no Basic tournaments. Make one first - the window says so and offers New Tournament. {{shot:05|The Choose a Tournament for PRO window with no rows: No Basic tournaments available, and Create a tournament to continue with the Tournament Pro upgrade.}}
  • Your tournament is not in the list. Only Basic tournaments appear. One that is already on Pro cannot be upgraded again.
  • Continue with PRO does nothing. No tournament is selected. Select a row first - it asks you to.
  • The price is not what you expected. Check the currency control beside the tabs. Prices are set per currency, not converted at checkout.
  • You do not want to pay yet. Select Close. Nothing is charged until you complete the checkout.
