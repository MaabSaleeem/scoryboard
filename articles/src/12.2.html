This article covers Football tournaments. Other Sports tournaments work exactly the same way. Padel is different and has its own articles.

Creating a tournament takes one form. Everything else - teams, format, fixtures - happens afterwards, on the tournament's own board.

Before you start

You need at least one saved venue. The form will not let you finish without one, and the picker only offers venues saved for tournaments. You can add one from inside the form, so this is not a reason to stop.

Steps

  1. Open Tournament in the sidebar, then select New Tournament. {{shot:01|The Tournament list with the New Tournament button outlined in the top right.}}
  2. The Create Tournament form opens. {{shot:02|The empty Create Tournament form showing Upload Logo, Tournament name, Game type, Start date, Start time, Match duration and Create or Select Clubs.}}
  3. Type a Tournament name. You get 50 characters. {{shot:03|The Create Tournament form with the Tournament name field outlined and filled in with Sunday Five-a-side.}}
  4. Leave Game type as Football.
  5. Choose a Start date. You cannot pick a date in the past - earlier days are greyed out. {{shot:04|The start date calendar open, with earlier days greyed out and today highlighted.}}
  6. Choose a Start time. Pick the hour, then the minutes, then AM or PM. All three are needed before the time is accepted. {{shot:05|The start time picker open with three columns - hours, minutes and AM or PM - and 10, 00 and AM selected.}}
  7. Set the Match duration in minutes. This is the length of one match, not the length of the tournament. {{shot:06|The Create Tournament form with the Match duration field outlined, set to 10 minutes.}}
  8. Open Create or Select Clubs and choose at least one venue.
  9. Select Create. {{shot:07|The completed form scrolled to the bottom, showing the selected venue, the Auto-start matches toggle, and the Create button outlined.}}

What you will see

You land on your new tournament's Participants tab with no teams on it yet.

{{shot:08|The new tournament's board on the Participants tab, showing the empty state and an Add Team button.}}

The tournament is already visible to anyone with the link. Add your teams next, then choose a format.

If it does not work

  • Create does nothing. A required field is empty. The name, game type, start date, start time and at least one club location are all needed. Scroll the form to find the one you missed.
  • Your venue is not in the list. The picker only shows venues saved for tournaments. A venue you created for a match will not appear. Use + in the picker to add it, and turn on Save for future tournaments.
  • The time will not stick. The picker needs all three parts. Choosing an hour but no minutes leaves the field empty.
  • Auto-start matches. Leave this off if you want to start each match yourself. Turn it on and matches begin at their scheduled time whether you are at the pitch or not.
  • You picked Padel and the form grew. Padel asks three more questions - Play mode, Enrollment type and whether it is a friendly tournament. Those are covered in the Padel articles, not here.
