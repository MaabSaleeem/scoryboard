A venue you add while setting up a tournament is used by that tournament only, unless you tick Save for future tournaments. A saved venue is offered again the next time you create a tournament, and it carries a Saved badge wherever it is listed.

Before you start

The tournament's Owner and its Admins can add venues to it. Only the account that added a venue can edit it. The Owner cannot edit a venue an Admin added, and an Admin cannot edit the Owner's. Nobody can remove a venue from a tournament once it is on it.

Choosing or adding a venue when you create a tournament

  1. Select New Tournament and open Create or Select Clubs. Your saved tournament venues are listed. Tick the ones this tournament will use. {{shot:01|The Create Tournament form with the Location Club list open under Start time. One venue is listed, KB 22 Cup Ground with a pink Saved badge and the address Mile End Stadium, London. The row is outlined in red. A blue plus button sits at the top right of the list.}}
  2. To add a venue that is not listed, select the + at the top of the list. Type the Club name and the Location.
  3. Tick Save for future tournaments if you will use this venue again. Leave it unticked for a one-off venue. {{shot:02|The Add new club location form filled in with KB 22 Scratch Pitch and Deptford Park, London. Below the fields, a grey panel reads Save for future tournaments, Reuse this club location the next time you create a tournament, with its box ticked. The panel is outlined in red.}}
  4. Select Continue. The venue is added to the list and ticked for this tournament.

The list here shows saved tournament venues only. The venues you use for ordinary matches are a separate list and do not appear. See {{link:22.1|Venues - adding, finding, editing and logos}}.

Venues on an existing tournament

  1. Open the tournament's Settings and scroll to LOCATION. Every venue on the tournament is listed, whoever added it. The Saved badge marks the ones kept for reuse. {{shot:03|The LOCATION card on a tournament's settings page. Under Club Location, three venues are listed: KB 22 Admin Pitch, KB 22 Cup Ground with a Saved badge, and KB 22 Overflow Pitch. The + Location button at the top right of the card is outlined in red.}}
  2. Select + Location to add another venue. The same form opens, with the Save for future tournaments box.
  3. To change a venue you added, select the three dots on its row and choose Edit. There is no Remove.

A venue can also be added from the fixture dialog when you schedule a group. See {{link:14.3|Bulk-scheduling a football group, and the gap between matches}}.

What an Admin can and cannot do

An Admin sees the same LOCATION card as the Owner and can add venues with + Location. Editing a venue somebody else added is refused.

  1. As an Admin, select Edit on a venue the Owner added and change a field.
  2. Select Continue. The form stays open and shows Club location can only be modified by its creator. Nothing is saved. {{shot:04|The Edit Location form for KB 22 Overflow Pitch, opened by an Admin. The Location field reads Wick Road, London (edited) with a red border, and beneath it the red line Club location can only be modified by its creator is outlined in red.}}

Where each kind of venue shows up

  • Tournament-only venue, added with the Save box unticked: on that tournament's settings page and in its fixture dialog. Nowhere else.
  • Saved tournament venue, added with the Save box ticked: on the tournament, in the Create Tournament list for your next tournament, and in Profile settings with the Saved badge.
  • Match venue, added from Profile settings or a match form: on match forms and in Profile settings. Not offered for tournaments.

If it does not work

  • You cannot edit a venue on your own tournament. An Admin added it. Ask them, or add your own venue with + Location.
  • A venue you added last time is not in the Create Tournament list. The Save for future tournaments box was unticked, so it belongs to that tournament only. Add it again and tick the box.
  • You want to take a venue off the tournament. There is no control for this. Edit it to a venue you will use, or leave it unused when you schedule fixtures.
  • You cannot open the tournament's Settings. You are not the tournament's Owner or an Admin, and the app sends you back to the home page. See {{link:24.1|You do not have permission to do that}}.
