Saving a padel format builds the bracket and fills it. Only the tournament Owner and an Administrator can change it.

Everyone else is sent to the tournament's public page, which has no Format tab.

Reading the bracket

  1. Open the tournament and select Format. The Knockout Phase card holds the bracket. {{shot:01|The padel Knockout Phase card showing the Swiss Finals bracket with semi-finals and a final.}}
  2. Look at the first round. Every slot already names a group position. {{shot:02|A semi-final match outlined, its two slots reading "1st Group A" and "4th Group A".}}

This is the difference from football. A football bracket starts empty and you fill it. A padel bracket is seeded for you: first plays fourth, second plays third, and the winners meet in the final.

Putting a named team in a slot

  1. Select the edit control on the slot you want to change.
  2. Search for the team, or create one. {{shot:03|The Add Team dialog with a search field, offering to select or create a team for this match slot.}}
  3. Select Add.

Renaming a match

  1. Select the edit control beside the match title. {{shot:04|The Edit match title dialog with the current knockout match title in a text field.}}
  2. Type the new title and select Save.

Renaming, resizing and deleting the bracket

  1. Select Edit on the bracket header to change its name or its size. {{shot:05|The Edit bracket dialog showing the bracket name and a Number of teams field set to 4 teams.}}
  2. Select the delete control on the bracket header to remove it. Its matches go with it. {{shot:06|The Delete bracket dialog asking whether to delete this bracket and all its matches.}}

If it does not work

  • You wanted to choose the teams yourself. Use the edit control on each slot. The seeding is a starting point, not a rule.
  • A "Winner Match" slot will not open. It cannot be edited. It fills itself when that match finishes.
  • You deleted the bracket by mistake. There is no undo. Delete the format and set it up again - see "Editing a group in a padel tournament".
  • You were looking for Fill automatically. That is a group control, not a bracket one - see "How pairs are created and grouped in a padel tournament".
