A tournament team belongs to the tournament. Adding one creates a new team - it does not pull in a team you already run. That surprises people, so it is worth knowing before you start typing.

This describes a tournament played between teams, which is how Football and Other Sports tournaments work. A Padel tournament can be entered by individual players instead - see the Padel articles.

Before you start

You need to be the tournament's owner or one of its admins.

Adding teams

  1. Open the tournament, then Participants, then Teams. {{shot:01|An empty Participants tab reading No teams added yet, with the Add Team button outlined.}}
  2. Select Add Team.
  3. On Single team, type one name. Add a logo if you have one. {{shot:02|The Add Team dialog on the Single team tab with a name typed in.}}
  4. For a whole draw at once, switch to Multiple teams and put one team on each line. The count underneath tells you how many it has read. {{shot:03|The Add Team dialog on the Multiple teams tab with three team names on separate lines and the text 3 teams ready to add.}}
  5. Select Save. {{shot:04|The Participants tab listing eight teams, each with a member count and an Add player button.}}

Giving a team an owner

You do not have to run every team yourself. Hand one over and its owner manages their own squad.

  1. Select the three dots at the end of a team's row. {{shot:05|A team row menu open showing Edit, Add Owner and Remove team.}}
  2. Choose Add Owner. {{shot:06|The empty Add Owner dialog asking for a name and a player email.}}
  3. Enter their name and email address, then select Continue. {{shot:07|The Add Owner dialog filled in with a name and email, with the Continue button outlined.}}

What you will see

The team's member count goes up straight away, and Add player is no longer offered on that row.

{{shot:08|The KB 12 Reds row showing one team member and a greyed-out Add player button.}}

The invitation goes to the email you entered. Until they accept it, the team is theirs on paper only - so send it early if you want them picking their own squad.

Pro or Basic

Whether a tournament gets Tournament Pro is decided when you create it, not here. The banner on your tournament list tells you how many free Pro tournaments you have left.

{{shot:09|The tournament list with the Free Tournament Pro slots remaining banner outlined. The remaining count is hidden.}}

If it does not work

  • Your existing team is not in the list. There is no list to pick from. Add Team creates a new team that belongs to this tournament. Type the name and it is created.
  • Add Owner is greyed out. That team already has an owner. Use Edit to change the team, or Remove team and add it again if you need to start over.
  • The multiple-teams count is lower than you expected. It counts lines. A blank line between names is ignored; two names on one line count as one team.
  • The owner cannot see the team. They need a Scoryboard account on the email address you used, and they need to accept the invitation.
