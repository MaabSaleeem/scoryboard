You add a friend with a name. That is the only thing Scoryboard asks for. They do not need an account, and adding them does not send them anything.

Add a friend

  1. Select Friends in the sidebar, then Add Friend. {{shot:01|The Friends screen with the Add Friend button outlined, top right.}}
  2. The window opens with two fields and an invitation link above them. {{shot:02|The Add Friend window: a Generate invitation link button, then Enter a name and Enter an email.}}
  3. Type their name in Enter a name. It is the only field you must fill in.
  4. Add their address in Enter an email if you have it. This is optional. It does not invite them and it does not create an account for them - it is a note on the record.
  5. Select Add Friend. {{shot:03|The Add Friend window with a name and an email typed in, and the Add Friend button outlined.}}
  6. The new row appears at the bottom of your list. {{shot:04|The friends list with the new row at the bottom, outlined.}}

On the Free plan you can hold 14 friends. The fifteenth opens a Friend Limit Reached window. See "Every Free-plan limit, and the messages you will see".

Change or remove a friend

  1. Select the three dots at the end of their row. The menu has Edit and Remove. {{shot:05|A friend row's three-dot menu open, showing Edit and Remove, outlined.}}
  2. Select Edit to change the name or the email, then select Update Friend. {{shot:06|The Edit Friend window with the name and email already filled in and an Update Friend button.}}
  3. Select Remove to take them off the list. Scoryboard asks first. {{shot:07|The Remove Friend window: Removing this user from your Friend List will also remove them from any teams you've added them to. This action can't be undone.}}
  4. Select Remove in that window to confirm, or Cancel to stop.

Read the warning before you confirm. Removing a friend also takes them out of every team you put them in, and it cannot be undone.

Friends you cannot edit

If the row is a real Scoryboard account - a small blue person sits beside the name - Edit is greyed out. Their name and their address belong to them, so only they can change those. Remove still works, and so does Chat.

{{shot:08|The three-dot menu on a Scoryboard account's row, with Edit greyed out and outlined, and Remove still available.}}

If it does not work

  • Nothing happens when you select Add Friend. Check the email address. A malformed one stops the form without showing a message. Clear the field and try again - the address is optional.
  • "This field is required." The name is empty. Type a name.
  • You get Friend Limit Reached. Your list is at the Free limit of 14. Remove somebody you no longer need, or move to Pro, which is free during the beta.
  • Edit is greyed out. That row is a real account, not a name you typed.
  • You removed the wrong person. There is no undo. Add them again with Add Friend, and put them back in their teams.
