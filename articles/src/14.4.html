Padel uses the same Bulk Match Updates dialog as football, with one field renamed. Only the tournament Owner and an Administrator can use it; everyone else sees the read-only public page.

Before you start

The three things this article covers are in two different places. Rounds and courts are in the bulk dialog. The gap between rounds is not - it is in Padel Configuration on the Format tab.

Re-timing the rounds

  1. Open the tournament, select Schedule, and select BULK MATCH UPDATE on the group.
  2. Find Court number. This is the one field that differs from football, which calls it Pitch number. {{shot:01|The Bulk Match Updates dialog on a padel tournament, with the Court number field outlined.}}
  3. Leave Same start time per round ticked. It is what keeps the matches of a round starting together. {{shot:02|The Same start time per round tick box outlined, ticked, with its explanation below it.}}
  4. Set the Match date and the First match start time. {{shot:03|The dialog filled in with 17-10-2026 and 09:00 AM.}}
  5. Select Update Matches. Every match in the group moves to the date and the time you set. {{shot:04|The four rounds after the update, each with two matches on courts 1 and 2, and every one of the eight kicking off at 9:00.}}

The rounds keep their grouping and their courts. They do not keep their separate kick-off times. The picture above holds four rounds, and all eight matches now start at 9:00. That is what the dialog does: while Same start time per round is ticked you cannot set a gap, so there is nothing to space the rounds with.

To put the rounds back on a ladder, change a value in Padel Configuration and save. That rebuilds the fixtures from the format, one round every match duration plus gap. Do it before any match is played - the rebuild throws away every score.

Setting a court

Court number writes one court across every match it touches. Leave it empty to keep the courts Scoryboard assigned, which give each match in a round its own court.

Fill it in only when the whole group really is on one court. Doing it by mistake puts every match of a round on the same court at the same time - see "Why padel matches share a start time, and when that is a clash".

Changing the gap between rounds

  1. Select Format, then Configuration.
  2. Change Gap between rounds (minutes). {{shot:05|The Padel Configuration dialog with Gap between rounds (minutes) outlined, set to 10.}}
  3. Select Save and confirm. Saving rebuilds the fixtures with the new gap.

The step from one round to the next is the match duration plus this number. With 10-minute matches and a 10-minute gap, rounds are 20 minutes apart.

A round added later by the Continue banner takes the same step. It starts one duration plus one gap after the last round.

Round Robin ignores the gap

The gap works on Swiss, Americano, Mexicano and King of the Court. Those formats start all the matches of a round together, so there is a round to space.

Round Robin has nothing to space. It gives every match its own kick-off, one match duration after the last. Gap between rounds (minutes) is still on the dialog, still marked required - and changing it moves no fixture.

To re-time a Round Robin group, use the bulk dialog and clear Same start time per round. Duration and Time between matches become editable, and each kick-off is then the one before it plus those two added together.

If it does not work

  • Time between matches is greyed out. That is expected while Same start time per round is ticked. The round gap is in Padel Configuration, not here.
  • The rounds have turned into a flat list. The tick box was cleared. Tick it and update the group again.
  • Every match is now on court 1. A court number was set in the bulk dialog. Clear it and rebuild the fixtures from Padel Configuration.
  • The gap changes nothing. This is a Round Robin tournament - see Round Robin ignores the gap.
  • Saving the configuration lost your times. It rebuilds the fixtures. Re-time the group afterwards.
  • You cannot type in a number field. Use the up and down arrows in the field instead.
