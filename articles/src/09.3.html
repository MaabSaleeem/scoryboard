Five details say where and when a match is played. Change them in the gear menu's Edit window.

Before you start

Pitch number is only in the Edit window. The details form you see while a match is being set up has no pitch field at all.

The venue, the date, the duration and the team size are all needed before a match can be Scheduled. The pitch number is optional.

Set the where and the when

  1. Open the match, select the gear at the top right, and choose Edit. Everything the match already holds is filled in for you. {{shot:01|The Update your match window, showing STEP 3 with Date, Start time, Duration, Location Club, Team size and Pitch number.}}
  2. Open Location Club. The box arrives holding the venue the match is at, so clear it to see the rest. {{shot:02|The Location Club list open with KB 09 Astro and KB 09 Park listed. KB 09 Park is outlined, and Create club location sits above them.}}
  3. Open Date and choose a day. Today is ringed. {{shot:03|The date picker open on September 2026. Today, 1 September, is ringed and 30 September is outlined.}}
  4. Open Start time. Pick the hour, then the minutes, then AM or PM. {{shot:04|The start-time picker with three columns. The minutes column is outlined.}}
  5. Type a Duration in minutes and, if the venue has more than one pitch, a Pitch number. {{shot:05|Duration set to 90 and Pitch number set to 2, outlined.}}
  6. Select Update Match. {{shot:06|The match's details after saving: Wed 30 Sept 2026, KB 09 Park, pitch 2, 20:15, 5 VS 5 and 90 min.}}

What you will see

The details row is the record. It reads, in order: the referee, the leaderboard, the date, the venue, the pitch, the kick-off, the team size and the duration. Anything you left out is not shown.

Pitch number is free text. Put whatever the venue calls it - 2, 3G, Court B.

You can date a match backwards. Nothing before today is greyed out. That is how a match already played gets recorded.

If it does not work

  • The venue list only shows one venue. The box still holds the current one and is searching for it. Clear the box.
  • Your venue is not on Scoryboard yet. Select Create club location at the top of the list.
  • There is no pitch field. You are on the match's own details form, not the Edit window. Use the gear at the top right.
  • Nothing can be changed. The match has finished. A Finished match is permanent.
