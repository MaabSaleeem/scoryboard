Nothing you set up is final. The name, the date, the format and the venues can all be changed afterwards - they just live in different places.

Before you start

Only the tournament's owner and its admins can edit or delete a tournament.

What you change in settings

Open your tournament list, select the three dots on the card, then Edit. The Setup section holds the tournament's name, its start date and the match duration.

{{shot:01|The Setup section of the tournament settings page, showing Tournament name, Start date and Match duration.}}

What you change on the Format tab

The format is not in settings. Groups, phases and encounters are edited on the tournament's own Format tab, using the pencil beside each phase and group.

{{shot:02|The Format tab showing the Group Phase with Group A and Group B, each with a pencil and a bin icon.}}

Save each section on its own

Settings is a stack of separate blocks. Each has its own Discard and Save Changes, and each saves only itself.

{{shot:03|The Setup section with its Save Changes button outlined, and the Roles section beginning below it.}}

Change the name and add an admin in one visit and you need to save twice - once in Setup, once in Roles.

Deleting a tournament

Scroll to the bottom of settings, to Danger zone.

{{shot:04|The Danger zone section warning that deletion is permanent, with a Delete Tournament button.}}
  1. Select Delete Tournament.
{{shot:05|The Delete Tournament confirmation dialog with an empty confirmation box and the delete button greyed out.}}
  1. Type DELETE in the box. The button turns red once it matches.
  2. Select Delete Tournament.
{{shot:06|The confirmation dialog with DELETE typed in the box and the Delete Tournament button now active and outlined.}}

What you will see

The tournament goes, and so does everything in it: teams, groups, fixtures and results. It cannot be undone.

If it does not work

  • Your change disappeared. You saved a different block. Each section has its own Save Changes - use the one in the section you edited.
  • You cannot find the format settings. They are not in settings. Use the Format tab on the tournament board.
  • The delete button will not activate. The box needs DELETE in capitals, on its own.
  • Remove on the card menu. Your tournament list card also has a Remove. It does the same thing but does not ask you to type anything, so be careful with it.
