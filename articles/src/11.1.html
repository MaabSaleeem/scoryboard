Every match has a FACTS tab. It holds two panels.

  • Insights - five short sentences about each team's last five games.
  • Statistics so far - the two teams' records, side by side.

Both panels need the match to belong to a leaderboard. A match without one shows nothing here, before or after it is played.

Read the Facts tab

  1. Open Home. In the MATCHES panel, select Past Matches, then choose your match. The MATCHES tab on a team lists the same fixtures.
  2. Select FACTS. {{shot:01|A finished match with the FACTS tab outlined in the row of tabs above the match details.}}
  3. Read Insights. Each team gets five lines: goals scored in a row, goals conceded, days since the last game, the formation used most, and cards received. Every line covers that team's last five games. Blue lines are the home team and red lines are the away team. The colour marks the side, not good or bad news. {{shot:02|The Insights panel, with five blue lines for KB 11 Rovers on the left and five red lines for KB 11 City on the right.}}
  4. Read Statistics so far. Each column is that team's whole record in the leaderboard. Here Rovers have played four matches and City three, and Rovers' Biggest win is a 4-0 against a third team. {{shot:03|The Statistics so far panel: Leaderboard position, Won, Drawn, Lost, Goals per match, Goals conceded per match, Clean sheets, Biggest win and Biggest loss, with a figure for each team.}}

What you will see

This is not a head-to-head record. Every figure is that team's own, across all its matches in the leaderboard. So the two columns can be counted from a different number of matches, and a Biggest win can be against a team that is not in this match.

Goals conceded per match is always a dash. The figure is not sent to this screen. Open the team and read its GOALS / CONCEDED tile instead.

Clean sheets counts wins only. A 0-0 draw does not add one. See "How team and player statistics are calculated".

The Facts tab is the same before and after a match. It reads both teams' current records, so a match that has not been played yet shows the same two panels.

There is no form guide. Scoryboard has no row of W, D and L badges. The Insights lines carry that information instead.

When the Facts tab is empty

Both panels read "No insights available yet" and "No statistics available yet" when the match does not belong to a leaderboard. That is the only cause. The match tag makes no difference: a friendly in a leaderboard has all five insights.

{{shot:04|The Facts tab on a match with no leaderboard: both panels empty, reading No insights available yet and No statistics available yet.}}

Attach the leaderboard before kick-off. A match that has already finished cannot be changed, so its Facts tab stays empty.

If it does not work

  • Both panels are empty. The match is not in a leaderboard. See above.
  • The numbers do not match the two teams' games against each other. Each column is that team's whole record, not their record against each other.
  • Goals conceded per match shows a dash. This is correct. Read the team's GOALS / CONCEDED tile instead.
  • An insight looks out of date. Reload the page. Insights are rebuilt from the last five games each time it loads.
  • VIEW KEY does not explain the panels. It opens the KEYS list at the foot of the match. That list is a legend for the lineup and feed icons - yellow card, captain, Player Of The Match.
