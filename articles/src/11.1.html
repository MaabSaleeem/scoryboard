Every match has a FACTS tab. It holds two panels - Insights, which is five short sentences about each team's last five games, and Statistics so far, which puts the two teams' records side by side.

Both panels only work for a match that belongs to a leaderboard. A one-off match with no leaderboard shows nothing here, before or after it is played.

Read the Facts tab

  1. Open the match. From Home, in the MATCHES panel, select Past Matches and choose the match you want. You can also reach it from the MATCHES tab on a team.
  2. Select FACTS. {{shot:01|A finished match with the FACTS tab outlined in the row of tabs above the match details.}}
  3. Read Insights. Each team gets five lines, and every line is about that team's last five games - goals scored in a row, goals conceded, days since the last game, the formation used most, and cards received. The home team's lines are blue and the away team's are red. The colour is only the side; it does not mean good or bad. {{shot:02|The Insights panel, with five blue lines for KB 11 Rovers on the left and five red lines for KB 11 City on the right.}}
  4. Read Statistics so far. Each column is that team's whole record in the leaderboard - not their record against each other. In this match Rovers have played four and City three, and Rovers' Biggest win is a 4-0 against a third team. {{shot:03|The Statistics so far panel: Leaderboard position, Won, Drawn, Lost, Goals per match, Goals conceded per match, Clean sheets, Biggest win and Biggest loss, with a figure for each team.}}

What you will see

This is not a head-to-head record. It is the easiest thing to misread on the screen, because the two teams sit either side of one label. Every figure is that team's own, across all its matches in the leaderboard - so the two columns can be counted from a different number of games, and a Biggest win can be against somebody who is not in this match.

Goals conceded per match is always a dash. The figure is not sent to this screen. To see what a team has conceded, open the team and read its GOALS / CONCEDED tile.

Drawn is worked out, not counted. It is matches minus wins minus losses.

Clean sheets counts wins. A 0-0 draw does not add one. See "How team and player statistics are calculated".

The Facts tab is the same before and after a match. It reads both teams' current records, so opening it on a match that has not been played yet shows the same two panels.

There is no form guide. Scoryboard has no row of W, D and L badges anywhere. The Insights lines are where that information lives.

When the Facts tab is empty

If both panels read "No insights available yet" and "No statistics available yet", the match does not belong to a leaderboard. That is the only cause. The match tag makes no difference - a friendly in a leaderboard has full insights, and a league match outside one has none.

{{shot:04|The Facts tab on a match with no leaderboard: both panels empty, reading No insights available yet and No statistics available yet.}}

A match that has already finished cannot be changed, so its Facts tab stays empty. Attach the leaderboard before kick-off.

If it does not work

  • The panels are empty. The match is not in a leaderboard. See above.
  • The numbers do not match the two teams' games against each other. They are not meant to. Each column is that team's whole record.
  • Goals conceded per match shows a dash. Expected. Read the team's GOALS / CONCEDED tile instead.
  • An insight looks out of date. Insights are rebuilt from the last five games each time the page loads. Reload the page.
  • VIEW KEY does not explain the panels. It opens the KEYS list at the foot of the match, which is a legend for the lineup and feed icons - yellow card, captain, Player Of The Match. It says nothing about the Facts tab.
