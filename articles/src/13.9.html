A football bracket starts with empty first-round slots. You decide what goes in each one. Only the tournament Owner and an Administrator can.

Everyone else is sent to the tournament's public page, which has no Format tab.

Filling a slot with a group position

  1. Open the tournament and select Format. Find a first-round match with an empty slot. {{shot:01|A quarter-final match with its first Add Team button outlined.}}
  2. Select Add Team. The menu offers positions, not teams: first, second, third and fourth in each group, and Bye. Scroll for the rest of the list. {{shot:02|The slot menu open, listing 1st Group A, 1st Group B, 2nd Group A, 2nd Group B, 3rd Group A and more.}}
  3. Choose the position that should feed this slot.
  4. The slot now reads that position. It stays a position until the group phase is started. {{shot:03|The filled slot outlined, reading "1st Group A".}}

A Bye is a free pass. Use it when you have fewer teams than the bracket has slots.

Filling a slot with a named team

Sometimes you know who is playing and do not want to wait for a group. The round + beside each slot names a team outright.

  1. Select the + on the slot.
  2. Search for the team, or create one. {{shot:04|The Add Team dialog with a search field, offering to select or create a team for this match slot.}}
  3. Select Add.

Renaming a match

  1. Select the edit control beside the match title. {{shot:05|The Edit match title dialog showing the current title, Match C1, in a text field.}}
  2. Type the new title and select Save.

What you will see

Once the group phase is complete and you start the knockout phase, every position turns into the team that finished there. Until then it stays a position, and nobody can enter a score. See "Tournament phases - preview, start, end and undo".

If it does not work

  • The menu lists teams, not positions. The group feeding this bracket has already been played, so Scoryboard knows who they are.
  • The menu is missing options. It scrolls. There is one option per position in every group, plus Bye.
  • A later round will not open. Semi-final and final slots read "Winner Match ..." and cannot be edited.
  • Your slots came pre-filled. That is padel - see "Brackets in a padel tournament".
