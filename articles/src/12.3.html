Three of these live on the Create Tournament form. Teams do not - you add those once the tournament exists.

The date

Every tournament needs a start date. It defaults to today.

{{shot:01|The Create Tournament form with the Start date field outlined.}}

Open it to pick another day. Days before today are greyed out and cannot be chosen.

{{shot:02|The start date calendar open, showing earlier days greyed out and today highlighted.}}

The kick-off time

This is when the first match of the day starts. The picker has three columns: hours, minutes, and AM or PM.

{{shot:03|The start time picker open, showing the hours, minutes and AM or PM columns.}}

Choose one from each. The field stays empty until you have set all three.

The venue

Open Create or Select Clubs. It lists the venues you have saved for tournaments.

{{shot:04|The venue picker open over the Create Tournament form, listing two saved venues, each marked Saved.}}

You can pick more than one. If the venue you want is not there, select + in the top right of the picker.

{{shot:05|The empty Add new club location form with Club name, Location, and a Save for future tournaments toggle.}}

Enter the club name and the location. Turn on Save for future tournaments if you will use this venue again - that is what puts it in the picker next time. Then select Continue.

{{shot:06|The Add new club location form filled in, with the Continue button outlined.}}

The teams

Teams are not on this form. Create the tournament first, then add them from its Participants tab.

{{shot:07|The new tournament's Participants tab with the Add Team button outlined.}}

If it does not work

  • A venue you already use is missing from the picker. The tournament picker only shows venues saved for tournaments. A venue you created for an ordinary match lives in a separate list and will not appear here. Add it again with +, and turn on Save for future tournaments.
  • Searching by name finds nothing. The two venue lists do not overlap. Searching will not turn up a tournament venue, and it will not turn up a match venue either. Use the picker's own list.
  • Continue is greyed out. The club name and the location are both needed before it becomes active.
  • You picked the wrong day. The start date can be changed later from the tournament's settings, up until the tournament goes live.
