Padel uses the same Create Tournament form as everything else. Change the game type and three extra fields appear.

Before you start

You need at least one saved venue. You can add one from inside the form.

Steps

  1. Open Tournament in the sidebar, then New Tournament.
  2. Type a Tournament name.
  3. Open Game type. It starts on Football. {{shot:01|The Create Tournament form with a name filled in and the Game type field outlined, showing Football.}}
  4. Choose Padel. {{shot:02|The Game type list open, showing Football ticked, Padel and Other Sports.}}

    Two new fields appear straight away, and a third further down.

    {{shot:03|The form after choosing Padel, now showing Play mode and Enrollment type between Game type and Start date.}}
  5. Set Play mode. Play for score ends a match at a target number of points. Play for time ends it on the clock. {{shot:04|The Play mode list open, showing Play for time and Play for score with Play for score ticked.}}
  6. Set Enrollment type. Single for individual players, Doubles for pairs. This one is required - the form will not submit without it. {{shot:05|The Enrollment type list open, showing Single and Doubles.}}
  7. Turn on Friendly Tournament if you want an email address to be optional when you add padel players. {{shot:06|The lower half of the form with the Friendly Tournament toggle outlined and its note that email is optional when adding padel players.}}
  8. Choose the start date, the start time and the match duration.
  9. Choose at least one club location.
  10. Select Create.

What you will see

You land on the tournament's Participants tab, with nothing on it yet. Choose a format next.

{{shot:07|A new padel tournament's board on the Participants tab, showing the empty state and an Add Team button.}}

If it does not work

  • Create does nothing. Enrollment type is the field people miss. It only exists for padel, so it is easy to scroll past.
  • The extra fields vanished. You changed the game type back. Play mode, Enrollment type and Friendly Tournament belong to padel only.
  • You wanted Other Sports. That option uses the plain form, exactly as Football does. No extra questions.
  • You picked the wrong enrollment type. Set it before you choose a format - the format questions are built around whether you are running singles or pairs.
