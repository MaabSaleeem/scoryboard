Scoryboard makes two invitation links, and they do different things. Both open the same window for whoever receives them, so it is worth knowing which one you sent.

LinkWhere you get itWhat accepting it does
Your account's linkAdd Friend → Generate invitation linkadds that person to your list as a new row
One person's linktheir row → Edit → Generate invitation linkhands them the row you typed, which becomes their account

Send an invitation

  1. For a link anybody can use, select Friends in the sidebar, then Add Friend, then Generate invitation link. {{shot:01|The Send Invitation panel inside the Add Friend window: share buttons, and a Copy link field outlined.}}
  2. For one person's own link, open the three dots on their row, select Edit, then Generate invitation link. Only a name you typed has one - a row that is already an account does not. {{shot:02|The same Send Invitation panel, this time inside the Edit Friend window.}}
  3. Select Copy link, or one of the share buttons, and send it. The field is too narrow to show the whole address, so copy it rather than reading it.
  4. The person opens the link and sees this. Tell them to sign in first. {{shot:03|The Friend List Invitation window: You've received a Friends list invitation from a named person. Please Accept or Reject the invite. No, thanks and Accept, with Accept outlined.}}
  5. They select Accept. {{shot:04|The same window after accepting: Request completed successfully, with a Close button.}}
  6. They are now on your friends list, under the name on their own account. {{shot:05|A friends list row showing the person's account name, a small blue person beside it, and a working Chat button.}}

What you will see

If you sent one person's link, the name you typed is gone and the row is theirs. Anything you had already done with that record stays - teams you put them in keep them.

If you sent your account's link, nothing is replaced. You get one more row.

This only goes one way. The person who accepts joins your friends list. You are not added to theirs. If you want each other on both lists, you each have to send a link.

If it does not work

  • They opened the link and landed on the sign-in screen. The invitation is lost when that happens. Ask them to sign in, then open the link again.
  • There is no Generate invitation link on that person's Edit. That row is already a Scoryboard account, so there is nothing to hand over. Use your account's link instead.
  • The link looks cut off. The field is narrower than the address. Use Copy link.
  • They accepted and you cannot find them. They are on the list under the name on their account, not the name you typed. Look for that.
  • You are not on their list. That is how it works. Invitations go one way.
