You can download the whole fixture list as a file to print or send on.

Before you start

Exporting fixtures needs Tournament Pro. On the Basic plan the button opens an upgrade prompt instead.

Exporting

  1. Open the tournament and select Schedule.
  2. Select EXPORT FIXTURES. It sits above the groups and covers the whole tournament, not just the phase you are looking at. {{shot:01|The Schedule tab with the EXPORT FIXTURES button outlined, above the fixture list.}}
  3. Choose PDF or Excel. PDF is chosen for you. {{shot:02|The Export Fixtures dialog: PDF and Excel, and the groups and brackets listed under their phases with nothing ticked.}}
  4. Tick the groups and brackets you want, or use Select all. {{shot:03|The same dialog with every section ticked, the Selection chip reading ALL ON, and the Export button outlined.}}
  5. Select Export. The file downloads.

What you will see

The sections are grouped by phase, so a Group and Knockout tournament offers its groups under Group Phase and its bracket under Knockout Phase. Everything you tick goes into one file.

The file is a table, one row per fixture, with the phase, the group or bracket, the match, the two teams, the date, the kick-off time, the venue, the pitch, the referee and the status.

If it does not work

  • Export is greyed out. Nothing is ticked. Tick a group or use Select all.
  • You were asked to upgrade. Exporting needs Tournament Pro.
  • A section is missing. Only groups and brackets that exist are listed. A tournament with no knockout phase offers no bracket.
  • The times look wrong. The file uses the same kick-off times the Schedule tab shows. Fix them there first.
