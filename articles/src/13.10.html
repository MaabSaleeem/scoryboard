Everything you answered when you chose the format can be changed afterwards. Only the tournament Owner and an Administrator can.

Everyone else is sent to the tournament's public page, which has no Format tab.

Changing the configuration

  1. Open the tournament and select Format. Configuration sits in the Phases header. {{shot:01|The Phases header with the Configuration button outlined.}}
  2. Read the dialog. It holds every setting from the format screen, and three more below the fold: Win points, Loss points and Draw points. {{shot:02|The Padel Configuration dialog showing standings type, player count, rounds, courts, scoring, the gap between rounds and win points.}}
  3. Change Scoring to set the points a match is played to. {{shot:03|The Scoring list open, offering 12, 24, 32 and Custom.}}
  4. Change Courts to match the courts you actually have. Use the stepper arrows in the field. {{shot:04|The Courts field outlined, showing 3.}}
  5. Select Save, then read the warning and select Confirm Changes. {{shot:05|The Update Padel Configuration dialog, warning that the current scheduled matches will be reset and recreated.}}

What you will see

The scheduled matches are thrown away and built again from the new settings. Kick-off times, courts and round numbers all change. Anything you had set by hand on those matches is lost.

Do this before you publish the fixture list, not after.

If it does not work

  • You cannot type in a number field. Use the stepper arrows. Typing prepends a digit rather than replacing what is there.
  • The dialog will not save. Every field marked * is required. Scroll down - the points fields are below the fold.
  • You did not want the fixtures rebuilt. Select Cancel on the warning. Nothing is saved until you confirm.
  • You wanted a different format entirely. Configuration keeps the format you chose. To swap Swiss for Americano, delete the format - see "Editing a group in a padel tournament".
  • There is no Configuration button. You are not the tournament's Owner or an Administrator. Football and Other Sports tournaments have a Configuration button too - it opens a dialog headed Football Configuration, holding league type, match duration, win, draw and loss points, and the group questions. It is not this dialog, and the padel settings are not in it.
