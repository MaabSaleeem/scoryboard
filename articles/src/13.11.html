A phase is a stage of the tournament. Moving from one to the next is a deliberate act, and you can see what it will do before you do it. Only the tournament Owner and an Administrator can.

Everyone else is sent to the tournament's public page, which has no phase controls.

Before you start

Phase controls appear on the Results tab, and only when there is something to do. A tournament with one phase and nothing played shows none of them.

{{shot:01|The Results tab of a one-phase tournament: a standings table, no phase tabs and no phase banner.}}

Starting the next phase

  1. Open the tournament and select Results, then the tab for the phase you are in.
  2. Read the banner. Until every match in this phase has a score, Start Next Phase is greyed out and the banner tells you so. {{shot:02|The phase banner outlined, greyed, reading "This button becomes available after all matches in Group Phase have scores."}}
  3. Enter the last scores. The banner turns green. {{shot:03|The same banner in green, with the Start Next Phase button outlined and enabled.}}
  4. Select Start Next Phase. Nothing has happened yet - this is a preview. {{shot:04|The Start Knockout Phase dialog, showing the finished group standings on the left and the next phase's matches on the right.}}
  5. Check each slot. The position is on top and the team that finished there is underneath. {{shot:05|One match from the preview, its first slot reading "1st Group A" above the team that finished first.}}
  6. Tick Send tournament phase summary email if you want followers told that the phase has finished.
  7. Select Start.

What you will see

The next phase now holds real teams instead of placeholders, and its matches will take a score.

{{shot:06|The knockout phase after starting, its quarter-finals holding named teams instead of TBD.}}

Undoing a start

Started it early? The phase you just started carries an Undo.

  1. Select the tab for the phase you started. {{shot:07|The Undo card on the started phase, with the Undo button outlined.}}
  2. Select Undo and read the confirmation. Every team comes out of the phase, and anything recorded in it goes back to how it was. {{shot:08|The undo confirmation dialog, warning that all teams will be removed from the phase and recorded activity restored.}}
  3. Select Undo.

The placeholder slots come back, score entry is blocked again, and the green banner returns. You can start the phase again whenever you are ready.

Ending the last phase

The last phase has nothing to start. Once every match in it has a score, the banner offers End Phase instead.

  1. Select End Phase. {{shot:09|The End Group Phase card on the last phase, with the End Phase button outlined.}}
  2. Read the confirmation, and tick the summary email if you want followers told. {{shot:10|The End Group Phase dialog, saying this will mark all matches in the phase as finished, with a follower email option.}}
  3. Select End Phase.

Every match in the phase is marked finished. There is no undo for this one.

Padel: moving to the next round

A padel phase goes forward a round at a time, and that is not a phase change. Score every match in the round you are on, and a second banner appears in the same strip, above the phase banner.

It is headed Continue and the name of your format - Continue Swiss, Continue Mexicano, Continue King of the Court - and it reads "Complete the current round to create the next player combinations".

{{shot:11|The Results tab of a padel tournament, the Continue Swiss banner outlined above the Start Knockout Phase banner.}}

Select Continue. The new round appears under its own ROUND heading in the fixture list below, and the banner goes until every match in that round has a score too.

Football has no Continue banner. A football phase is generated whole and moves on with Start Next Phase.

King of the Court has one control more. Its End Phase dialog offers Create Playoffs beside End Phase. That builds a Final between the winners of the last round, as a phase of its own, and the new phase carries the same Undo as any other.

If it does not work

  • Start Next Phase is greyed out. A match in the current phase has no score. The banner names the phase it is waiting on.
  • There is no banner at all. There is nothing to do yet: one phase, and nothing played.
  • Undo is greyed out. A later phase has already been started. Undo that one first.
  • The knockout slots still read "1st Group A". The phase has not been started. Positions only turn into teams when you start it.
  • You ended a phase by mistake. Ending cannot be undone. Reopen the matches individually.
  • There is no Continue banner on your padel tournament. A match in the round you are on has no score. Score them all and the banner appears.
  • Continue opens "Round cannot continue". King of the Court does not allow a draw. The dialog says so. Give the tied match a winner - a golden point, or any other winning score - and select Continue again.
  • Create Playoffs is refused. The same reason, written in red inside the End Phase dialog: "King of the Court playoff matches cannot be created from a draw". Settle the tied match first.
