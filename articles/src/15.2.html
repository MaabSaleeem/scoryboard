One dialog holds the link to your public page and a QR code for it. Both are read-only, and both can be passed on to anybody.

Before you start

Share tournament is in the tournament header. You do not have to be the Owner to use it: the same dialog is on the public page, for anybody who opens it.

Getting the link

  1. Open your tournament and choose Share tournament in the header. {{shot:01|The Share Tournament dialog: the explanation, the link field, the QR code and Print QR code.}}
  2. Copy the link with the button beside it. The field itself is read-only, so you cannot select the text by hand. {{shot:02|The link field with the copy button beside it outlined.}}
  3. For a code to put on a wall or a table, choose Print QR code. It scans to the same address. {{shot:03|The QR code, with the Print QR code button below it outlined.}}
  4. Anybody looking at your public page can share it on. The same control is there for them, signed in or not. {{shot:04|The same Share Tournament dialog, opened by a visitor with no account.}}

What you will see

The link is your public page: People with this link can view your board but can't change it. Nothing in the dialog gives anybody the right to edit your tournament.

There is no confirmation when you copy. The link is on your clipboard.

If it does not work

  • Nothing happened when you pressed copy. There is no message either way. Paste it somewhere to check.
  • The link is greyed out and you cannot select it. That is the field being read-only. Use the copy button.
  • Somebody sent you a tournament access link and it will not open. An expired or mistyped one gives you this. {{shot:05|A page reading This tournament access link is invalid or expired.}} Ask them for the public link from this dialog instead.
