Every picture control in Scoryboard takes a JPG, GIF or PNG up to 3 MB. A comment attachment has to be under 2 MB. A video on a match feed has to be under 200 MB. This article tells you which message you are looking at and how to get past it.

The limits

WhereWhat it takesLimit
Your profile photo, a team crestJPG, GIF or PNG3 MB to choose from. Scoryboard crops and shrinks it before it uploads
Your profile banner, a team banner, a leaderboard bannerJPG, GIF or PNG3 MB
A photo on a commentAny image2 MB
A photo on a match feed (Pro)Any image3 MB
A video on a match feed (Pro)MP4, MOV or WebM200 MB

The comment box says 3 MB and the server stops at 2 MB. Keep comment photos under 2 MB and the message below will not appear.

What you will see

  1. Under every picture control the caption reads JPG, GIF or PNG. 3MB max. That is what you may choose. After you crop, Scoryboard converts the picture itself, so a photo that fits the caption uploads. {{shot:01|The PROFILE APPEARANCE card on Profile settings: a dark banner, a round avatar with the initial M, edit and delete controls, and the caption JPG, GIF or PNG. 3MB max. outlined in red.}}
  2. On a comment, a picture over 3 MB is refused before it leaves your device. The message names the file: File exceeds 3 MB: your-file.png. Remove it with the cross on its thumbnail and choose a smaller one. {{shot:02|The comment box on a team page with a thumbnail below it, Add Media and Comment buttons, and the red line File exceeds 3 MB: kb-24-team-photo.png outlined.}}
  3. A picture between 2 MB and 3 MB passes that check, is sent, and comes back File too large. Shrink it below 2 MB and try again. {{shot:03|The same comment box after choosing a smaller file, with the red line File too large outlined.}}
  4. On a match feed, a video over 200 MB is refused the same way: File exceeds 200 MB: your-file.mp4. Trim the clip or export it smaller. {{shot:04|The Add comment window on a match feed: an empty box, Add media, a 0/300 counter, a thumbnail, a Post button, and the red line File exceeds 200 MB: kb-24-highlights.mp4 outlined.}}

If it does not work

  • "Unsupported file type". The file is not a picture or a video. A PDF or a document cannot be attached to a comment.
  • The picker does not offer your video. Only the match feed takes video, and only on Pro. Comments take pictures only. On Free, Add media on the feed asks you to upgrade. See {{link:10.8|The match feed and commentary}}.
  • Your profile photo was refused after cropping. A very detailed picture can still be too large after Scoryboard shrinks it. Crop tighter, or start from a smaller picture.
  • Your bio disappeared when you changed your photo. That is a known fault. Add the bio again after the photo. See {{link:02.5|Your profile photo, banner and bio}}.
