The standings table is on the Results tab. It updates as scores go in.

Finding the table

  1. Open the tournament and select Results. {{shot:01|The Results tab with the Group Phase tab outlined, showing the standings tables for Group A and Group B.}}
  2. Select Group Phase. Once every group match has a score, the tab opens on the knockout phase instead, so you have to come back here.
  3. Read the table. One row per team, one column per number. {{shot:02|The Group A standings table with its column heading row outlined: PLD, W, D, L, PTS, GF, GA and GD.}}
  4. Open Fixtures under the table to see the matches the numbers came from. {{shot:03|The Fixtures list under the standings table, showing finished matches with their scores.}}

What the columns mean

  • PLD - matches played.
  • W, D, L - won, drawn, lost.
  • PTS - points. This is what the table is sorted on.
  • GF - goals for, the goals the team scored.
  • GA - goals against, the goals scored past them.
  • GD - goal difference, GF minus GA.

The number on the far left is the team's position. It decides who fills each knockout slot: a slot written 1st Group A takes whoever is first in this table when the phase starts.

If it does not work

  • Every number is zero. No match has a score yet. Play a match, or enter its result from Fixtures.
  • The table is not there. You are on the knockout phase. Select Group Phase.
  • Two teams are level. Points come first, then goal difference. You can also give a team bonus points when you start the next phase.
  • You expected a SCORE column. That is the padel table. Football counts goals - see "Reading the group standings table in a padel tournament".
