Everything you can do to a match after it is set up sits behind the gear at the top right.

Before you start

The gear belongs to the team's Owner, an Administrator and the match's referee. Anybody else sees the match and no controls.

There is no delete. The menu offers Configure appearance, Edit and Cancel Match. Cancelling takes the match out of every list; it does not remove it.

Edit or cancel

  1. Open the match and select the gear. {{shot:01|The gear menu open with three items: Configure appearance, Edit and Cancel Match. Edit is outlined.}}
  2. Choose Edit. Update your match opens with the match's details already in it. {{shot:02|The Update your match window, filled in with the leaderboard, both teams, the date, the time, the venue and pitch 3.}}
  3. Change what you need, then select Update Match. {{shot:03|The same window with Pitch number changed from 3 to 4, outlined.}}
  4. To call the match off, select the gear again and choose Cancel Match.
  5. Read the warning, then select Cancel Match a second time. {{shot:04|The Cancel Match window reading "This action cannot be undone. This will permanently cancel the match", with the red Cancel Match button outlined.}}

What you will see

A cancelled match disappears. It leaves your calendar, your team's fixtures and the leaderboard. Nothing in Scoryboard brings it back, so treat the warning as final.

Edit is the only way to change a match once it is Scheduled. The details form you filled in while setting it up is gone by then.

An unfinished match can be cancelled too. The gear is on it from the start, even before the match has a date.

What somebody who only plays for the team sees

No gear, so no Edit and no Cancel Match. They keep Add to Calendar, because a fixture is worth putting in your own calendar whoever runs it.

{{shot:05|The same match seen by a team player. The gear is gone from the header; only the calendar and share buttons are left.}}

If it does not work

  • There is no gear. You are not the Owner, an Administrator or the referee.
  • The Edit window opened empty. The match is not finished being set up, so there is nothing to fill in yet. See "Match statuses, and why a match is stuck on Incomplete".
  • The Referee box is blank on a match that has one. That field does not fill itself in. See "Assigning a referee, and adding a banner or note".
  • Nothing can be changed. The match has finished. A Finished match is permanent.
  • You cancelled the wrong match. Make a new one. There is no undo.
