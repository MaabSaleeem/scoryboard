Saving Group & Knockout or Knockout only builds a bracket. Only the tournament Owner and an Administrator can change it.

Everyone else is sent to the tournament's public page, which has no Format tab.

Reading the bracket

  1. Open the tournament and select Format. The Knockout Phase card holds the bracket and its rounds. {{shot:01|The Knockout Phase card showing Bracket C with quarter-finals, semi-finals and a final.}}
  2. Look at the first round. Both slots in every match read Add Team, because nothing has been decided yet. {{shot:02|A quarter-final match outlined, with two empty Add Team slots.}}
  3. Look at any later round. Its slots are already written for you, and you cannot edit them. {{shot:03|A semi-final slot outlined, reading "Winner Match C1".}}

A bracket of eight teams gives you quarter-finals, semi-finals and a final. Four teams gives semi-finals and a final. Two gives a final.

Renaming and resizing the bracket

  1. Select Edit on the bracket header. {{shot:04|The Edit bracket dialog with a Bracket name field and a Number of teams field.}}
  2. Change the Bracket name if you want to. The name is used in every match title.
  3. Open Number of teams to change how big the bracket is. {{shot:05|The Number of teams list open, offering 2 teams, 4 teams and 8 teams.}}
  4. Select Save. The rounds are rebuilt to fit.

Deleting the bracket

  1. Select the delete control on the bracket header.
  2. Read the confirmation. Deleting a bracket deletes its matches too. {{shot:06|The Delete bracket dialog asking whether to delete this bracket and all its matches.}}
  3. Select Delete.

If it does not work

  • The first-round slots are still empty. That is normal. Fill them yourself - see "Setting and renaming bracket matches in a football tournament".
  • A "Winner Match" slot will not open. It cannot be edited. It fills itself when that match finishes.
  • Resizing lost your slot choices. Changing the number of teams rebuilds the rounds. Set the slots again afterwards.
  • Your bracket is pre-filled with group positions. That is padel - see "Brackets in a padel tournament".
