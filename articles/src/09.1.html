A match takes two teams and five details. Create Match makes the match on the click, then you fill it in.

Before you start

You need a team, and you need a leaderboard to put the match in. Every match needs one, even a friendly. See "Match tags, and attaching a match to a leaderboard".

The match exists as soon as you select Create Match. Nothing asks you to confirm. If you close the tab now, a half-built match is left on your team's fixture list. See "Match statuses, and why a match is stuck on Incomplete".

Create the match

  1. Open Schedule and select Create Match. You can also start from a team page, which fills the home team in for you. {{shot:01|The Scheduled Matches calendar for September, with the Create Match button outlined at the top right.}}
  2. You land on Match Settings. The match is already made. Select Add Home Team. {{shot:02|The new Match Settings page with an empty MATCH DETAILS form. The Add Home Team button is outlined.}}
  3. Choose a team from Select team, or type its name in the search box. {{shot:03|The Add Team window with a search box, a Select team list, a Create Team link and an Add button. The Select team list is outlined.}}
  4. Select Add. The team's crest appears at the top of the window first. {{shot:04|The Add Team window with KB 09 United chosen, its crest above the search box, and the Add button outlined.}}
  5. Do the same for Add Away Team. Typing searches every team on Scoryboard, not only yours. {{shot:05|The match card with both teams in place and a green Friendly badge between them.}}
  6. Choose a Leaderboard. {{shot:06|The Leaderboard list open, with KB 09 Sunday League outlined and a Create Leaderboard row above it.}}
  7. Choose a Location Club. Select the box to see your venues. {{shot:07|The Location Club list open, showing KB 09 Astro and KB 09 Park with a Create club location row above them.}}
  8. Choose a Date. {{shot:08|The date picker open on September 2026 with 24 outlined.}}
  9. Choose a Start time. Pick the hour, the minutes, then AM or PM. {{shot:09|The start-time picker with three columns: hours, minutes, and AM or PM. PM is outlined.}}
  10. Set Duration in minutes and Team size, then select Save changes. {{shot:10|The saved match. The form has gone and a read-only row reads Thu 24 Sept 2026, KB 09 Astro, 19:00, 5 VS 5 and 60 min.}}

What you will see

The form is replaced by the match's details. That is how you know the match is ready. Above them, a countdown reads how long until kick-off, and a line says This match will start automatically at the scheduled time and date.

Everybody in either line-up is told. A Match scheduled notification goes out on its own. You do not have to invite anybody.

If it does not work

  • The team you added is still not showing. The card does not redraw after you select Add. Reload the page and it is there.
  • Nothing happened when you selected Save changes. The match saves whatever you have filled in, even if that is not enough. If the details row did not replace the form, something is still missing. See "Match statuses, and why a match is stuck on Incomplete".
  • Your venue is not in the list. Type its name to search every venue on Scoryboard, or select Create club location to add your own.
  • You cannot find the leaderboard you want. You have to be a member of it. Select Create Leaderboard at the top of the list to make a new one.
