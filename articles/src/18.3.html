Every message has a menu. This article shows you what is on it and what each item does.

Before you start

Replying to somebody else's message, and reacting to one, both need Pro. On Free you can send messages and edit or delete your own, but an incoming message is cut short and you cannot act on it. Pro is free during the beta.

The menu on somebody else's message

  1. Move your pointer over the message. A small arrow appears in its top corner.
  2. Select the arrow. The menu offers Reply, Copy, React, Forward, Report and Delete for me. {{shot:01|The message menu on an incoming message, listing Reply, Copy, React, Forward, Report and Delete for me.}}
  3. Choose Reply. The message you are answering sits above the message box. {{shot:02|The message box with a Replying to Milo KB strip above it, quoting the message being answered.}}
  4. Type your answer and send it. The quote travels with it, so everybody can see what you replied to. {{shot:03|A sent reply in the transcript, carrying the quoted message above it.}}
  5. Choose React for a quick answer without typing. Six reactions are offered. {{shot:04|The reaction picker, offering thumbs up, heart, laughing, surprised, crying and folded hands, with a Close button.}}
  6. The reaction appears under the message with a count. Choose the same one again to take it back. {{shot:05|A message carrying a thumbs-up reaction and a count of one, with the reaction outlined.}}
  7. Choose Forward to send the message on. Tick the conversations it should go to, then select Forward. {{shot:06|The Forward Message window, with a preview of the message and a list of conversations to send it to.}}

The menu on your own message

  1. Open the menu the same way. It adds Edit and Delete for everyone, and drops Report. {{shot:07|The message menu on your own message, listing Reply, Copy, React, Forward, Edit, Delete for me and Delete for everyone.}}
  2. Choose Edit. The message turns into a box you can type in. {{shot:08|A message open for editing, with Cancel and Save buttons and the Save button outlined.}}
  3. Change the text and select Save. The message then shows edited beside its time, so nobody is misled about what was first sent.
  4. Choose Delete for me to take a message off your own screen, or Delete for everyone to remove it for the whole conversation. {{shot:09|A transcript showing one message marked edited and another reading This message was deleted.}}

What you will see

A message you delete for everyone leaves This message was deleted in its place for the other people in the conversation. On your own screen it disappears completely.

If it does not work

  • Reply and React do nothing. You are on Free and the message is somebody else's. Both need Pro.
  • Deleting asks nothing and cannot be undone. There is no confirmation on either delete and no way to bring a message back. Read the menu before you select.
  • Forward stays off. Tick at least one conversation. You cannot forward into the conversation you are already in.
  • There is no Edit. You can only edit your own messages.
