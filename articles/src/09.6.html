A match can carry a note, a cover image and a referee. You can set the note and the cover image. The referee you cannot.

Before you start

All of this belongs to the team's Owner and an Administrator. The match's referee can edit the note too.

The referee

You cannot add a referee to an ordinary match. The field is there. The list behind it is not a list of people on Scoryboard.

It holds only referees you saved earlier, while setting up a tournament. If you have never run one, the list is empty. Typing a name finds nothing, however you spell it.

{{shot:01|The Update your match window with "Rae KB" typed into the Referee box. The list below reads No results found, outlined.}}

So tell your referee yourself. Put the arrangement in the match note instead - see below.

Some matches do have a referee: a tournament fixture, or a match set up by somebody who had one saved. Their name comes first in the match's details.

{{shot:02|The match's details row with the referee's name, Rae, outlined at the start, ahead of the leaderboard and the venue.}}

The Referee box stays blank even then. It does not read the name back off the match. The details row is the record.

A referee is never told. Putting somebody on a match sends them nothing.

The cover image

  1. Select the gear and choose Configure appearance. {{shot:03|The Configure appearance window with a camera tile, an Upload a cover image link outlined, and a Select a theme list.}}
  2. Select Upload a cover image and choose a picture, or open Select a theme. There is one theme, Default Theme. {{shot:04|The theme list open. Default Theme is its only entry, outlined and ticked.}}

The note

  1. Open FEED on the match. With no note it reads No Note added. beside an Add Note link. {{shot:05|The FEED panel with "Note: No Note added." and the Add Note link outlined.}}
  2. Select Add Note, or Edit if there is one already. Type up to 250 characters and select Save. {{shot:06|The Edit Note window holding "Meet at the clubhouse 20 minutes before kick-off. Bring both kits." and a 66/250 counter. Save is outlined.}}

What you will see

The note is on the match page, not in a message. Everybody who opens the match reads it. Nobody is sent it.

The cover image is the picture behind the match's title. It changes nothing else.

If it does not work

  • The referee list is empty. It always is, unless you saved a referee while setting up a tournament. Nothing on a match adds one.
  • There is only one theme. Yes. Upload a cover image if you want the match to look different.
  • Your note was cut off. The limit is 250 characters. The counter under the box tells you where you are.
  • There is no gear on the match. You are not the Owner, an Administrator or the referee.
