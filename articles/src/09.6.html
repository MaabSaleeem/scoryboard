Three things you can put on a match: a referee, a cover image and a note. Two of them are yours to set.

Before you start

All three belong to the team's Owner and an Administrator. The match's referee can edit the note too.

The referee list is not a search of everybody on Scoryboard. It only offers referees you have already saved while setting up a tournament. If you have never run one, it is empty and stays empty.

The referee

  1. Open the match, select the gear, choose Edit, and find Referee under STEP 3.
  2. Type a name. With no saved referees the list reads No results found, whoever you type. {{shot:01|The Update your match window with "Rae KB" typed into the Referee box. The list below reads No results found, outlined.}}
  3. A match that does have a referee shows their name first in its details. {{shot:02|The match's details row with the referee's name, Rae, outlined at the start, ahead of the leaderboard and the venue.}}

The cover image

  1. Select the gear and choose Configure appearance. {{shot:03|The Configure appearance window with a camera tile, an Upload a cover image link outlined, and a Select a theme list.}}
  2. Select Upload a cover image and choose a picture, or open Select a theme. There is one theme, Default Theme. {{shot:04|The theme list open. Default Theme is its only entry, outlined and ticked.}}

The note

  1. Open FEED on the match. With no note it reads No Note added. beside an Add Note link. {{shot:05|The FEED panel with "Note: No Note added." and the Add Note link outlined.}}
  2. Select Add Note, or Edit if there is one already. Type up to 250 characters and select Save. {{shot:06|The Edit Note window holding "Meet at the clubhouse 20 minutes before kick-off. Bring both kits." and a 66/250 counter. Save is outlined.}}

What you will see

The note is on the match page, not in a message. Everybody who opens the match reads it. Nobody is sent it.

The referee is not notified. Somebody put on a match as its referee gets no notification about it at all.

If it does not work

  • The referee list is empty. It only offers referees you saved while setting up a tournament. There is no way to add one from a match.
  • The Referee box is blank on a match that already has one. That field does not fill itself in from the match. The name in the match's details is the real record.
  • There is only one theme. Yes. Upload a cover image if you want the match to look different.
  • Your note was cut off. The limit is 250 characters and the counter under the box tells you where you are.
