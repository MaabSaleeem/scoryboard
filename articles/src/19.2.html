A comment has three controls: Reply, a thumbs-up and a reply count. This article covers all three.

Before you start

You have to be a member of the team or the leaderboard to reply or to like. Everybody else can read. See {{link:19.1|Commenting on a team or a leaderboard}}.

Reply to a comment

  1. Select Reply under the comment. A second box opens beneath it. {{shot:01|A comment by Ollie with a reply box open under it, outlined. The box has Add Media, Cancel and Reply.}}
  2. Type your answer and select Reply. Select Cancel to drop it instead.
  3. To read the answers to a comment, select View n more replies. Replies sit indented under the comment they answer. {{shot:02|Ollie's comment with Pia's reply "I will bring the bibs." shown indented below it and outlined.}}

Like a comment

  1. Find the thumbs-up beside the comment. The number next to it is how many people have liked it, not whether you have. {{shot:03|A comment with Reply, an outlined grey thumbs-up showing 1, and a speech bubble showing 1.}}
  2. Select the thumbs-up. It turns blue and the count goes up by one. {{shot:04|The same comment with the thumbs-up now solid blue and the count reading 2.}}
  3. Select it again to take your like back. The count drops and the thumbs-up goes grey.

What you will see

Grey means you have not liked it. Blue means you have. A comment can show a count of 3 and still be grey, if none of those three is you.

The speech bubble is the reply count. It is not a button that does anything different from View n more replies.

A reply is a comment. It cannot be edited or deleted either, and it can be liked.

You cannot edit or delete a comment

Scoryboard has no way to change a comment or remove one, on this screen or anywhere else. That is true of your own comments as well as everybody else's, and it is true of replies.

If you posted something wrong, add another comment putting it right. If somebody else posted something that should not be there, ask the team's Owner or the leaderboard's Owner. Deleting the team or the leaderboard is the only thing that clears its comments, and that removes everything else with them.

If it does not work

  • Reply is greyed out. You are not a member of the team or the leaderboard. Ask to be added.
  • You cannot find the replies. They are folded up. Select View n more replies under the comment.
  • The count did not move when you liked it. Give it a second. If it still has not, reload the page.
  • You are looking for an edit or a delete. There is not one. See the section above.
