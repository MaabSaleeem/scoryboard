The Presentation tab controls what a visitor sees. It decides which of the six public tabs are there, and it is where you write your info page.

Before you start

You need to be the Owner or an Administrator of the tournament. Presentation has two halves, Website and Slideshow. This article is the Website half. Read {{link:15.4|Building a match-day slideshow}} for the other.

Choosing which tabs are public

  1. Open your tournament, choose Presentation, then Website. Every tab is on when a tournament is created. {{shot:01|The Presentation tab, Website selected, showing the two sub-tabs, the six switches, Open website and Save.}}
  2. Untick a tab you do not want the public to see. {{shot:02|The six switches with the Chat switch unticked and outlined.}}
  3. Choose Save. Nothing changes for anybody until you do. {{shot:03|The Website card with the Save button outlined.}}
  4. The tab is gone from your public page. Tick it again and save to bring it back. {{shot:04|The public tab strip with five tabs and no CHAT.}}

Writing your info page

  1. On Website, use the small pencil on the Info row. It has no label, so it is easy to miss. {{shot:05|The six switches with the pencil on the Info row outlined.}}
  2. The card is replaced by Page with tournament information: a description, pictures and attachments. {{shot:06|The info page editor, empty, with Description, Pictures and Attachments.}}
  3. Write a description. It is capped at 200 characters.
  4. Use Add a picture for images, and Add an attachment for a file people can download. Attachments take any file type, so a PDF is fine. {{shot:07|The info page editor with a description written, one picture added and one PDF attached.}}
  5. Choose Save. All three appear at the top of your public Info tab. {{shot:08|The public Info tab showing the description, a Gallery section with one picture, and an Attachments section with a PDF download link.}}

What you will see

Open website opens your public page in a new tab. It is the quickest way to check your own work.

An attachment renders as a download link, with the filename in capitals. A picture goes into a Gallery section.

If it does not work

  • You cannot find where to edit the info page. It is the pencil on the Info row, not on the tab itself.
  • Your description stops part way. The field takes 200 characters.
  • The tab you turned off is still there. You have not saved yet.
  • A picture will not upload. The Pictures block takes images only. Use Attachments for anything else.
