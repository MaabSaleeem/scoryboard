A group chat lets you message a whole squad at once. This article builds one and shows you what its admin can change.

Before you start

Whoever creates a group is its Admin. Only an admin can rename a group, add or remove people, hand out admin, or delete the group. A member can read, send and leave, and nothing else.

The Leaderboards, Teams and Friends sources are empty unless you have one. Anyone always works.

Creating the group

  1. Open Chat, then select + at the top of the Chats list. {{shot:01|The Start New Chat window, with Create Group Chat outlined.}}
  2. Choose Create Group Chat. Now choose where to find the players. {{shot:02|The Select Players window listing four sources: Leaderboards, Teams, Friends and Anyone, with Teams outlined.}}
  3. Pick the source, then the team or leaderboard, then tick each player you want. Select all takes everybody at once. {{shot:03|The player list for a team, with two players ticked and the Next button outlined.}}
  4. Select Next. Give the group a name and check who is in it. {{shot:04|The Create Group Chat window with a name typed in, its character counter, and two participants listed.}}
  5. Select Create chat. The group opens, and everybody you picked is added. {{shot:05|The new group open, with lines reading Pru KB created the group, Milo KB joined the group and Otto KB joined the group.}}

What you will see

The name is optional and holds up to 80 characters. Leave it empty and the group is named after its first two members. You can change it later.

Setting the group up

  1. Select the group's name at the top of the conversation. That opens Group Info. {{shot:06|The Group Info window as an admin, showing the group photo, name and description pencils, the Announcement only switch, the participant list with an Admin badge, and the Add button outlined.}}
  2. Use the pencils to change the name and the description, and the buttons above them to change the group photo.
  3. Turn Announcement only on to stop members sending messages. Admins can still send.
  4. Select Add to bring more players in. You choose the source the same way you did when you created the group.
  5. Select the menu beside a member for Make admin and Remove member.

If it does not work

  • A source is empty. You have no team, no leaderboard or no friends yet. Use Anyone and search for the player instead.
  • Create chat does nothing. Pick at least one player. The button stays off until you do.
  • You cannot see the pencils or Add. You are a member, not an admin. Ask an admin to make you one.
