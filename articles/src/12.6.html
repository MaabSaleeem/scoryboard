A tournament cannot be created without a venue. You can add one while you are creating it, and you can add more later.

Before you start

Only the tournament's owner and its admins can change venues on an existing tournament. Anyone creating a tournament sets the first one.

Choosing a venue when you create the tournament

Create or Select Clubs is a required field on the Create Tournament form.

{{shot:01|The Create Tournament form with the Create or Select Clubs field outlined and empty.}}

Open it to see the venues you have saved for tournaments. You can tick more than one.

{{shot:02|The venue picker open over the Create Tournament form, listing two saved venues, each marked Saved.}}

Adding a venue that is not on the list

  1. Select + at the top right of the picker.
  2. Enter the Club name and the Location.
{{shot:03|The Add new club location form filled in with a club name and a location.}}
  1. Turn on Save for future tournaments if you will play there again. This is what puts the venue in the picker next time.
{{shot:04|The Add new club location form with the Save for future tournaments toggle outlined.}}
  1. Select Continue. The venue is added and selected.

Venues on a tournament you have already created

Open the tournament's settings and scroll to Location. Every venue on the tournament is listed, and + Location adds another.

{{shot:05|The Location section of the tournament settings page, listing one venue with a Saved label and a plus Location button.}}

What you will see

Venues appear on the tournament's public page: a count under No. of locations, and each one listed with its address.

{{shot:06|The public tournament page showing No. of locations set to 1 and Location 1 naming the venue and its address.}}

If it does not work

  • A venue you use for matches is not in the picker. Tournament venues are a separate list. A venue saved for an ordinary match will not appear here, and searching will not find it. Add it again with + and tick Save for future tournaments.
  • The venue you added is not there next time. You left Save for future tournaments off. It stays on the tournament you added it to, but it is not offered again.
  • Continue is greyed out. Both the club name and the location are required.
