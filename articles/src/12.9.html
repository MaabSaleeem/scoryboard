Referees are added to the tournament, not booked from a directory. You create them here, on the tournament's own Participants tab.

Before you start

You need to be the tournament's owner or one of its admins.

Steps

  1. Open the tournament, then Participants, then Referees. {{shot:01|An empty Referees tab reading No referees added yet, with the Add Referee button outlined.}}
  2. Select Add Referee. The dialog opens on Saved referees - the officials you have kept from previous tournaments. {{shot:02|The Add referee dialog on the Saved referees tab, showing a search box and the message No saved referees yet.}}
  3. For someone new, switch to Single referee. A first name is required; last name and email are optional. {{shot:03|The Add referee dialog on the Single referee tab, with fields for first name, last name and email, and two toggles.}}
  4. To add a whole crew, use Multiple referees and put one name on each line. {{shot:04|The Add referee dialog on the Multiple referees tab with two names on separate lines and the text 2 referees ready to add.}}
  5. Decide what they are allowed to do, then select Add Referee.

The two toggles

Save for future tournaments keeps them in your Saved referees list, so you do not retype them next time.

Allow referee to start and end matches lets them control matches themselves from the Results tab. Leave it off and match control stays with you and your admins.

{{shot:05|The Add referee dialog with the Allow referee to start and end matches toggle outlined.}}

What you will see

Your referees are listed on the Referees tab, with a search box once the list gets long.

{{shot:06|The Referees tab listing two referees by name.}}

If it does not work

  • Saved referees is empty. It only fills up when you tick Save for future tournaments as you add someone. It does not collect them automatically.
  • Add Referee will not activate. On Single referee the first name is required. On Multiple referees you need at least one line.
  • Your referee cannot start a match. The permission is set when you add them. Remove them and add them again with the toggle on.
  • The list does not show who can control matches. It does not, so keep a note if it matters to you.
