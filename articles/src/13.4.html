A padel group has one editable thing: its name. Only the tournament Owner and an Administrator can change it.

Everyone else is sent to the tournament's public page, which has no Format tab.

Renaming a group

  1. Open the tournament and select Format. The group header carries an edit control, and no delete control. {{shot:01|A padel group header with its edit control outlined. There is no delete control beside it.}}
  2. Select Edit. The dialog has a Name field and nothing else. {{shot:02|The Edit group dialog for a padel group, showing only a Name field.}}
  3. Type the new name and select Save.

Why there is no size or encounters field

A football group holds a Number of teams and an Encounters setting. Padel keeps both somewhere else: the player count, the rounds and the courts all live in Configuration. See "Changing a padel format after you have saved it".

Removing the group

There is no way to delete a padel group on its own. The group and the knockout phase are two halves of one format, and they go together.

  1. Find the delete control in the Phases header, at the top right of the board. {{shot:03|The Phases header with the Delete format control outlined, beside the Configuration and Phase buttons.}}
  2. Read the confirmation. It deletes the group phase and the knockout phase. {{shot:04|The Delete Swiss format dialog, warning that this deletes the complete format including its group and knockout phases.}}
  3. Select Delete.

What you will see

The board goes back to Choose a format, with the five padel formats to pick from. Your pairs stay on the Participants tab.

If it does not work

  • You wanted to delete one group and keep the rest. Padel makes one group. There is no "rest" to keep.
  • You only wanted to change the number of players. Do not delete the format. Open Configuration instead.
  • The name did not save. The field cannot be empty. Type a name and try again.
