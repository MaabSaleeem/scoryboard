You can re-time every fixture in a group in one go. Only the tournament Owner and an Administrator can do it; everyone else sees the read-only public page.

Before you start

One tick box decides whether this works the way you expect. Same start time per round is ticked when the dialog opens, and while it is ticked Duration and Time between matches are both greyed out. A football group has no rounds, so leaving it ticked puts every fixture in the group on the same kick-off time.

Re-timing a group

  1. Open the tournament, select Schedule, and find the group.
  2. Select BULK MATCH UPDATE. This covers every fixture in that group. {{shot:01|The Group A header with SELECT MATCH TO UPDATE and BULK MATCH UPDATE, the second one outlined.}}
  3. Read the dialog as it opens. Duration and Time between matches are greyed out. {{shot:02|The Bulk Match Updates dialog with Same start time per round ticked and the two greyed-out fields above it.}}
  4. Clear Same start time per round. Both fields become editable. {{shot:03|The same dialog with the tick box cleared and the Time between matches field outlined and now editable.}}
  5. Set the Match date and the First match start time.
  6. Set Duration and Time between matches, both in minutes. {{shot:04|The dialog filled in: 10:00 AM, 15 minutes duration and 20 minutes between matches.}}
  7. Select Update Matches. {{shot:05|The group re-timed under a WEEK 1 heading, kicking off at 10:00, 10:35, 11:10, 11:45, 12:20 and 12:55.}}

What you will see

Each kick-off is the one before it plus the duration plus the gap. A 15-minute match with a 20-minute gap puts 35 minutes between kick-offs: 10:00, then 10:35, then 11:10.

You do not have to fill everything in. Only the fields you set are applied, so you can move a group to a new date and leave its times alone.

Your fixtures sit under a WEEK heading. The Schedule tab groups a football group by week. A group whose fixtures all fall in one week shows a single WEEK 1 band above them.

A fixture with no date sits under UNSCHEDULED. That band is the last one, under the weeks. It appears only when a fixture is in it, and a fixture there reads Incomplete until it is given a date. See "Rescheduling fixtures, and rolling them onto the next day" for how a fixture gets there.

If it does not work

  • Duration and Time between matches are greyed out. Clear Same start time per round. That is what unlocks them.
  • Every match now starts at the same time. The tick box was left on. Clear it, set a gap, and update the group again. See "Why two football fixtures clash, and fixtures showing only one team".
  • Nothing saved. The dialog needs at least one field filled in before it will save.
  • Fixtures moved to another day. You set an End time. A match rolls to the next day when it would finish past that time. The field is only on a group-and-knockout tournament, so this dialog does not show it. See "Rescheduling fixtures, and rolling them onto the next day".
  • You only want to move some matches. Use SELECT MATCH TO UPDATE instead. It opens the same dialog.
